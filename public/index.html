Slides

    Slide editor

    Each deck is one JSON file, and they all sit together in slide-decks/decks/.

    Open deck edits one .json in place; Save writes back to that file, the same one your IDE and git see.

    Open folder (pick slide-decks or slide-decks/decks) lets you switch decks, create new ones, and preview images from slide-decks/assets.

    This browser cannot write to local files, so Save downloads the deck instead. Chrome, Edge, and Arc save in place.
